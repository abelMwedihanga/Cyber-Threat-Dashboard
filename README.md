# 🛡️ Cyber Threat Dashboard

A Python Flask SOC dashboard that combines Port Scanner + Phishing Checker + Log Analyzer in one web app.

Built by Abel Mwedihanga | NAMPOL | MSc Cyber Security

## Features
- **Port Scanner** - Scan common ports on any host
- **Phishing URL Checker** - Score URLs for phishing risk
- **Log Analyzer** - Count failed logins and find top attacking IPs

## How to Run (cmd)
- install pip install -r requirements.txt
- python app.py

## Tech
Python + Flask + HTML/CSS
